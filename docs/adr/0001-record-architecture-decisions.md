# ADR-0001: Record architecture decisions

- Status: accepted
- Date: 2026-10-07

## Context

OpenLabel is an open-source project with contributors who were not present for earlier discussions. Decisions need to be discoverable, with their reasons.

## Decision

Significant technical decisions are recorded as numbered Markdown files in `docs/adr/`, using this template (context, decision, consequences). An ADR is never rewritten after acceptance; a later ADR supersedes it and both link to each other.

## Consequences

New contributors can find why things are the way they are. Each significant change in a pull request includes or references an ADR.
