## Description

Waveform editor for segments, transcripts and speakers, plus ASR evaluation for any speech engine (Whisper, cloud APIs) through engine adapters.

## Acceptance criteria

- [ ] Waveform editor: create/resize segments, play/loop, speed control, transcript and speaker fields
- [ ] Metrics: WER, CER, substitution/deletion/insertion counts, per-speaker WER, diarization error rate
- [ ] WER matches jiwer on fixtures with the same normalisation
- [ ] Exporters: JSONL manifest, Hugging Face audio dataset

- See ADR-0004 (task types) and ADR-0005 (scaling).
