## Description

Single- and multi-label classification for documents, images, audio clips and text: keyboard-first labelling UI and evaluation.

## Acceptance criteria

- [ ] Labelling UI with hotkeys per class and multi-label toggle
- [ ] Metrics: accuracy, macro/micro precision/recall/F1, confusion matrix, top-k, expected calibration error
- [ ] Metrics match scikit-learn on fixtures
- [ ] Exporters: ImageFolder, CSV/JSONL, Hugging Face datasets

- See ADR-0004 (task types) and ADR-0005 (scaling).
