## Description

Rework the two screens labellers live in, per the user's chosen layouts.

## Acceptance criteria

- [x] Nested folders per project (any depth): create, rename, delete-empty; move files between folders
- [x] Uploading a folder from the computer keeps its structure
- [x] Project page as a file browser: folder tree left; files of the selected folder right as a dense list or thumbnail grid; one-line stats in the header; Upload button + drop anywhere; Files / Exports tabs; status filter
- [x] Export the whole project or chosen folders
- [x] Full-screen labelling workspace (no app chrome): thin top toolbar with back, file name, position, prev/next, save; floating tool palette on the left; inspector on the right with a magnified crop of the selected word above its text field; film-strip of pages at the bottom
- [x] Responsive: tree collapses to a folder picker on small screens; inspector becomes a bottom sheet
- [x] Folder data access org-scoped and tested
