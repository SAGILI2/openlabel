## Description

Labelling bank slips and documents needed the page and its text side by side, boxes that land in
the right line, pages turned the right way up, and multi-page PDFs. Design references:
`docs/design/ocr-box-inspector.html` and `docs/design/ocr-pdf-pages.html`.

## Acceptance criteria

- [x] Page at 70% width; right panel split 45% selected box / 55% text by line, both dividers draggable (double-click resets, sizes remembered)
- [x] Every word in the text panel is its own field; clicking one selects and edits exactly that word; a curved link joins the selected box to its word
- [x] Dragging on empty page space draws a box that snaps to the ink and is filed into the line it sits on, in reading order; moving or resizing keeps its line unless it clearly leaves
- [x] Right-click a box or word for actions (edit, snap, zoom, move line, reorder, delete); line/word move, snap and delete pinned in the panel header
- [x] Display settings (boxes, link, file strip) are on/off toggles saved per person in the database and follow them everywhere
- [x] No browser scrollbars in the editor; the file strip can be hidden; swiping on the page no longer flips to the previous/next file
- [x] OCR turns sideways and upside-down pages upright (orientation model, then the more confident of the two readings) and records how it decided, for per-model orientation metrics
- [x] PDF upload: one file, every page rendered and OCR'd; editor shows one page at a time with a page strip (checked status, turn badge, word count) only when there are several pages; PgUp/PgDn
- [x] Exports turn each saved PDF page into its own image, turned upright like photos
- [x] Word state: corrected (text differs from what the OCR read, compared exactly, case-sensitive), confirmed (marked correct, C), drawn, or OCR draft; shown in the text panel, on the page and in the box card, with undo to the OCR reading
- [x] Orientation metrics on project Settings (model accuracy, accuracy by its confidence, turns needed); turning a page by hand in the editor re-reads it that way, turns saved boxes with it, and counts as the right answer
- [x] Re-run OCR: "No text" filter, re-run on selected files or all files with no text (labels kept; one open job per file; turns from the editor jump the queue); the 4,669 empty pages re-read
