## Description

Send invitations, password resets, email verification and later notifications by email. Templates
are React components (React Email); sending goes through the job queue so mail can be retried,
rate-limited and scheduled for later.

## Acceptance criteria

- [ ] Templates in a `packages/emails` workspace (React Email), previewable locally, light/dark-safe
- [ ] Mail transport adapter: `smtp` (any provider, e.g. Mailtrap live or sandbox), `log` (prints to console) and `noop`; chosen by `MAIL_TRANSPORT`
- [ ] Sending is a queued job with retries and back-off; `sendAt` schedules future mail
- [ ] `MAIL_REDIRECT_ALL_TO` sends every message to one inbox (safe for staging)
- [ ] Invitations, password reset and email verification send real emails; invite link still shown in the UI
- [ ] Integration test against a local SMTP catcher (e.g. Mailpit) in Docker Compose

## Technical notes

- Config names are generic (`MAIL_TRANSPORT`, `MAIL_FROM`, `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_SECURE`) so any SMTP provider works; Mailtrap is a supported, documented example, not a dependency.
- Mailtrap `live.smtp.mailtrap.io` delivers to real recipients; use the Mailtrap sandbox host or `MAIL_REDIRECT_ALL_TO` in development.
- Credentials only in `.env` (gitignored); never committed.
