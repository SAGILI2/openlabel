## Description

Choosing reviewers page by page doesn't scale. Labellers send a selection or a whole folder for
review in one step; reviewers see what's waiting for them and approve or request changes in bulk.

## Acceptance criteria

- [x] "Send for review" in the file browser: the selected pages, or every page with saved labels in the current folder; pick reviewers once (project default reviewers always included)
- [x] Pages already in review, approved, or with only an OCR draft are skipped, with the reason shown
- [x] Each reviewer gets one email for the batch, linking to their queue
- [x] "Waiting for me" filter shows the pages the signed-in reviewer was asked to review
- [x] Bulk Approve / Request changes (reason required) on the selection or the filtered view, with the same rules as one page: reviewer roles only, no self-approval unless allowed, current version only
- [x] Data access tested (bulk submit, bulk review, permissions, one email per reviewer)
