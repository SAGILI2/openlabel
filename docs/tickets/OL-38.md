## Description

Labels, fields and individual regions can declare what their text must look like (alphabetic, numeric, alphanumeric, integer, decimal, currency, percentage, date, time, email, phone, URL, code, or a custom pattern). The editor validates while labelling and suggests fixes for common OCR confusions (letter O vs zero, I vs 1); evaluation uses the type to normalise values (e.g. `1,250.00` equals `1250.00` for a decimal field).

## Acceptance criteria

- [x] 14 presets plus options: decimal/thousands separators, currency symbols, date layouts, extra allowed characters, upper-case only, min/max length, custom pattern
- [x] Unicode-aware: alphabetic presets accept any script (e.g. Devanagari)
- [x] Western and Indian digit grouping both accepted (1,250,000 and 12,50,000)
- [x] Fix suggestions for OCR confusions, never applied automatically
- [x] Numeric normalisation for evaluation (grouping removed, locale decimal separator handled)
- [x] Regions can override the label's value type
- [x] Unit tests for every preset (accept and reject cases)
- [ ] Taxonomy editor: pick a preset, set options, preview test values
- [ ] Canvas editor: inline invalid-value warning with one-key "apply suggestion"
- [ ] Evaluation: field metrics use the type's normalisation
