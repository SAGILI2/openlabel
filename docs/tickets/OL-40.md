## Description

Benchmark (frozen snapshot), engine, eval run, per-item raw + canonical result and metric rows with slices and confidence intervals, independent of task type.

## Acceptance criteria

- [ ] Tables and migrations for benchmark, engine, eval_run, eval_result, eval_metric
- [ ] Runs are chunked, idempotent and resumable across workers
- [ ] Raw responses stored so runs can be re-scored without calling the API again
- [ ] Bootstrap confidence intervals computed in the core for any per-item metric

- See ADR-0004 (task types) and ADR-0005 (scaling).
